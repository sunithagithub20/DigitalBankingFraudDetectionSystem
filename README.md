# Digital Banking Fraud Detection & Simulation Engine

## Description
This project is a Java-based application that detects fraudulent banking transactions.  
It analyzes transactions using predefined rules and classifies them as Normal, Suspicious, or Fraud.

## How It Works
- A transaction is given as input  
- The system checks rules like amount, frequency, and unusual behavior  
- Fraud detection logic is applied  
- The transaction is classified as:
  - Normal  
  - Suspicious  
  - Fraud  
- Results are stored and can be viewed for analysis  

## Tech Stack
- Java  
- Spring Boot  
- REST APIs  
- MySQL  
- Thymeleaf

  #How to run
  mvn springboot:run
